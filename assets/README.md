# Mascot concept

`intentacle-logo.png` is the original approved AI-generated concept: a purple
octopus holding a task card, with the Intentacle wordmark and sticker outline.
The file is a 1254 × 1254 RGBA PNG.

This foundation uses the original raster image without modification. Vector,
small-icon, monochrome, and print-production variants have not been prepared.

Artwork is excluded from the npm package. The README points to a pinned copy in
GitHub so it can display the mascot without bundling the PNG with the CLI. Git
history retains the original image; no history rewrite was performed.
